Functions

What are Functions?

Functions are reusable blocks of code designed to perform specific tasks. Instead of repeating the same code multiple times, logic is wrapped in a function and "called" whenever the system requires it. This modular approach ensures the program remains organized, readable, and efficient.

How Functions Work

A function operates as a three-part process, turning raw data into finished results:

  • Inputs (Parameters): These act as the raw materials "fed" into the function so it has specific data to work with.
  • The Logic: This is the internal set of instructions that performs the actual calculation, comparison, or transformation on the input.
  • Outputs (Return Values): This is the final result that the function "spits out" or returns once its job is complete, allowing that data to be used elsewhere in the system.

Function Blueprints: Named vs. Arrow Functions

In JavaScript, functions can be constructed using different syntax styles, depending on how the logic engine needs to execute them:

  • Named Functions: Created using the traditional function keyword. These act as permanent, standard components in your system that are highly readable and can be referenced anywhere within their scope.
  • Arrow Functions: A modern, streamlined syntax designed for writing shorter, cleaner code. They act as "lightweight processors," making them ideal for quick, single-line operations or passing quick logic inline.

Named Function Example

function calculatePower(current, voltage) {
    return current * voltage;
}


console.log(calculatePower(5, 220));

Arrow Function Example

const calculatePower(current, voltage) => {
    return current * voltage;
}


console.log(calculatePower(5, 220));
