Array

What is an Array?

An array functions like a row of storage lockers where each locker is assigned a specific number, starting from zero. Instead of creating multiple individual variables for ten different items, a single array holds all of them in one organized structure.

How Arrays Work

Interacting with these lists involves several core JavaScript methods that allow for precise data management:

  • Indexing: Every item in an array has a position number known as an index. Data is retrieved by "calling" its specific number (e.g., item[0]).
  • Adding Data (push): This method adds a new data packet to the very end of the list, similar to a new task arriving at a processing gateway.
  • Removing Data (pop): This method removes the last item from the end of the list, effectively shortening the array.
  • Finding Data (indexOf): This command searches the entire row to identify the exact position where a specific piece of information is located.

Creating an Array & Indexing

const storageLockers = ["Data_A", "Data_B", "Data_C"];


console.log(storageLockers[0]);
console.log(storageLockers[2]);

Adding Data

const processingGateway = ["Task_1", "Task_2"];

processingGateway.push("Task_3");

console.log(processingGateway);

Removing Data with

const systemQueue = ["Packet_A", "Packet_B", "Packet_C"];

const removedItem = systemQueue.pop();

console.log(removedItem);
console.log(systemQueue);

Finding a Position with

const securityLog = ["User_10", "User_25", "User_88"];

const targetIndex = securityLog.indexOf("User_25");

console.log(targetIndex);
