HCI Consideration

  • Consistency and Standards: Every page utilizes a uniform layout with navigation controls placed at the bottom, ensuring that users can predict where to find essential buttons like "Home" or "Next".
  • Aesthetic and Minimalist Design: The interface uses high-contrast colors and plenty of whitespace to ensure that content is the primary focus, preventing cognitive overload for the learner.
  • Recognition Rather Than Recall: Standardized icons—such as the house for Home and arrows for navigation—leverage existing user knowledge so they don't have to relearn how to interact with the site on each page.
  • User Control and Freedom: Each page provides clear "Exit" and "Home" options, giving users the freedom to leave a module or reset their session at any point without feeling trapped.
