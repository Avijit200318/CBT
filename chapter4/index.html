Stack

What is a Stack?

A stack operates like a vertical pile of dinner plates or a stack of books. In this environment, the system can only interact with the item at the very top. To access the bottom item, every piece of data sitting above it must be removed first.

How the Stack Works

Managing a stack in JavaScript involves two primary actions that control the flow of data:

  • Push: This operation adds a new data packet onto the very top of the stack.
  • Pop: This operation removes the most recent item from the top of the stack.
  • The "Back" Button Logic: This structure powers real-world features like a browser’s "Back" button or a text editor’s "Undo" command, where the last action taken is always the first one to be reversed.

Initializing a Stack

const createStack = () => {
    return {
        bookStack: [],
        topIdx: -1
    };
};

The Push Operation

const pushElement = (stack, element) => {
    stack.bookStack.push(element);

    stack.topIdx++;

    console.log(`Pushed: "${element}"`);
};

The Pop Operation

const popElement = (stack) => {

    if (stack.topIdx === -1) {
        console.log("Stack Underflow: The silo is empty!");
        return null;
    }

    const removed = stack.bookStack.pop();
    stack.topIdx--;

    console.log(`Popped: "${removed}"`);
    return removed;
};

Print Top Element

const printTopElement = (stack) => {

    if (stack.topIdx === -1) {
        console.log("The stack is empty. No top element.");
        return;
    }
    
    console.log("Top Element is:", stack.bookStack[stack.topIdx]);
};
