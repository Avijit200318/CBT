Problem

Your application monitors a temperature sensor that records data hourly into an array. To keep the data clean, you need to fix an incorrect reading, add a new reading, discard a trailing faulty data packet, and locate the exact position of a specific baseline temperature.

  • You are given a starting data log array: let tempLogs = [18, 22, 14, 25, 12];.
  • Modify Data: Access the third item in the array (index 2) and change its value to 16.
  • Add Data: Use an array method to add a new temperature reading of 20 to the end of the array.
  • Remove Data: Use an array method to remove the last item from the array and store it in a variable called discardedReading.
  • Find Data: Find the index position of the temperature value 22 and store it in a variable called baselineIndex.
  • Lastly, print three things to the console: the final tempLogs array, the discardedReading variable, and the baselineIndex variable.
