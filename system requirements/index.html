System Requirements

Hardware Requirements

  • Processor: Dual-core 2.0 GHz or higher (Intel i3/AMD Ryzen 3 equivalent).
  • RAM: Minimum 4 GB (8 GB recommended for seamless 3D element rendering).
  • Storage: 500 MB of free disk space for local installation.
  • Display: 1366 x 768 resolution minimum (1920 x 1080 Full HD recommended for storyboard clarity).

Software Requirements

  • Operating System: Windows 10/11, macOS High Sierra or later, or Linux (Ubuntu 20.04+).
  • Web Browser: Google Chrome (v90+), Mozilla Firefox (v88+), or Microsoft Edge.
  • Media Support: Integrated HTML5 Media Player with enabled JavaScript and hardware acceleration.
  • Resolution: Best viewed in a maximized window or full-screen mode..

  • Display: 1366 x 768 screen resolution or higher for a clear layout.

Software Requirements
