Queue

What is a Queue?

A queue functions like a line of people waiting at a grocery store or a row of cars at a toll booth. In this system, the first piece of data to enter must be the first one to leave. This ensures that every task is processed in the exact order it arrived, preventing newer data from "cutting in line."

How the Queue Works

Managing a "Service Line" in JavaScript involves two essential operations that maintain a smooth flow of information:

  • Enqueue: This action adds a new data packet to the very back of the line, similar to a new customer joining a queue.
  • Dequeue: This action removes the item from the very front of the line, representing a completed task being sent to the processor.
  • Real-World Use: This logic powers everyday technology, such as printers handling a list of documents or a web server managing a high volume of incoming user requests.

Initializing a Queue

const createQueue = () => {
    return {
        dataQueue: [],
        frontIdx: 0,
        backIdx: -1
    };
};

The Enqueue Operation

const enqueueElement = (queue, element) => {
    queue.dataQueue.push(element);
    queue.backIdx++;
    console.log(`Enqueued: "${element}" | Back Index: ${queue.backIdx}`);
};

The Dequeue Operation

const dequeueElement = (queue) => {
    
    if (queue.frontIdx > queue.backIdx) {
        console.log("Queue Underflow: The line is empty!");
        return null;
    }

    const removed = queue.dataQueue.shift();
    
    console.log(`Dequeued: "${removed}" | Remaining items: ${queue.backIdx + 1}`);
    return removed;
};

Print Front Element

const printFrontElement = (queue) => {
    if (queue.frontIdx > queue.backIdx) {
        console.log("The queue is empty. No front element.");
        return;
    }
    
    console.log("Front Element is:", queue.dataQueue[queue.frontIdx]);
};
