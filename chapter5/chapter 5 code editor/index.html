Queue Related Problem

Your office server handles incoming print requests using a Queue structure governed by FIFO (First-In-First-Out) logic. You are given a queue system object tracking incoming documents. Your job is to add new print documents to the back of the queue, process (remove) the oldest document from the front, and check which document is currently next in line.

  • You are given an initial tracking object: let printerQueue = { dataQueue: [], frontIdx: 0, backIdx: -1 };.
  • Enqueue three string values onto the back of the queue in this exact sequence: "Report.pdf", "Invoice.docx", and "Image.png". Remember to increment backIdx each time you add a value.
  • Dequeue the first item from the front of the queue using the shift() array method to process the oldest document. Remember to decrement backIdx to keep your counter aligned with the shortened array.
  • Lastly, print the current front element of the queue to the console using your frontIdx tracker variable.
