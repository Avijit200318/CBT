Datatypes and Variables

What are Variables?

Variables are digital storage boxes used to reserve a specific spot in the computer's memory for data. In JavaScript, choosing the right container is essential for system stability:

  • let: Used for information that needs to change or update, such as a mission score or a timer.
  • const: Used for information that must stay the same, such as a unique ID or a fixed mathematical constant.

Identifying Data Types

Data in JavaScript comes in different "shapes" or types. Each type tells the computer how to treat the information:

  • Strings: Used for text-based data (e.g., "Agent_007" or "System Online").
  • Numbers: Used for all mathematical values, counting, or calculating durations (e.g., 25 or 3.14).
  • Booleans: Used for simple logic gates — True or False — to determine if a mission is active or a task is complete.

The "Var" Legacy

Var: Before let and const, JavaScript used var. In modern coding, we avoid it because it is "function-scoped," which can lead to memory leaks and unpredictable bugs in complex algorithms. Sticking to let and const is the first step in writing secure code.

Dynamic Typing

Flexible Containers: Unlike some languages where a "Number box" can only ever hold numbers, JavaScript is dynamically typed. This means a variable created as a String can be reassigned to hold a Number. While flexible, a good developer keeps data types consistent to prevent system crashes.

Type Checking

System Diagnostics: To ensure your mission logic is sound, you can use the typeof command. It acts like a scanner that tells the computer exactly what kind of data is inside a "storage box" before you try to process it.
